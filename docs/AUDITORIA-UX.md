# Auditoría UX/UI - Aplicación de notas

## Heurísticas de Nielsen

| Heurística | Problema | Solución |
|---|---|---|
| Visibilidad | No mostraba mensajes. | Se agregaron avisos. |
| Mundo real | El botón decía "ok". | Se cambió a "Agregar nota". |
| Control | Eliminaba sin preguntar. | Se agregó confirmación. |
| Prevención | Permitía notas vacías. | Se agregó validación. |
| Reconocimiento | No tenía etiqueta. | Se agregó un label. |

## Leyes de usabilidad

- Fitts: Botones más grandes de 44px.
- Hick: Acciones claras y organizadas.
- Miller: Formulario y notas separados.

## Mejoras realizadas

Se mejoraron los colores, botones, etiquetas,
contraste y navegación con teclado.

## Conclusión

La aplicación ahora es más fácil de usar,
evita errores y tiene mejor accesibilidad.
